# Greenden

This is a responsive multi-page website built using **HTML** and **Tailwind CSS**.

🌍 **Live Demo:** [Greenden Live Website](https://manickamm7.github.io/greenden-tailwind/)

## 📄 Pages Included

* **Home** (`index.html`) - The main landing page.
* **Product** (`product.html`) - Displays the list of products or services.
* **Contact** (`contact.html`) - Contains contact information and an inquiry form.

## 🛠️ Technologies Used

* **HTML5** - For structuring the web pages.
* **Tailwind CSS** - For styling and responsive design.
